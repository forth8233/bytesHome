# 部署与运维

## 适用范围

本文档面向内测环境，覆盖 Home Agent 后端（FastAPI + SQLite）、前端静态资源、Home Assistant 连接、健康检查、日志、备份、限流与 72 小时稳定性验收。

## 运行环境与依赖

- Python 3.12，后端虚拟环境位于 `backend/.venv`
- Node.js 20+ 与 npm，用于构建前端
- Home Assistant 可访问，且已创建长期访问令牌
- 单个 SQLite 数据库文件，默认 `backend/data/agent.db`

后端必须单进程运行。会话、SSE 连接、快路径缓存、慢路径限流计数都保存在进程内，多 worker 会导致状态分裂和重复执行风险，启动参数固定使用 `--workers 1`。

## 目录结构

```text
byteAgent/
  backend/           FastAPI 服务、测试、数据库
  frontend/          Vue 3 + Vite 前端
  logs/              运行日志与 soak 采样
  tools/             运维与压测脚本
  docs/              部署与运维文档
  docker-compose.yml 可选的 Home Assistant 本地编排
```

## 配置项

配置从 `backend/.env` 读取，环境变量优先。以下为运维相关项：

| 变量 | 默认值 | 说明 |
| --- | --- | --- |
| `HA_BASE_URL` | `http://127.0.0.1:8123` | Home Assistant 地址 |
| `HA_TOKEN` | 空 | Home Assistant 长期令牌，禁止提交到仓库 |
| `APP_SECRET_KEY` | 开发占位值 | JWT 签名密钥，生产必须替换为随机长字符串 |
| `APP_ENCRYPTION_KEY` | 空 | 可选，用于加密 LLM API Key；为空时由 `APP_SECRET_KEY` 派生 |
| `DATABASE_URL` | `sqlite+aiosqlite:///./data/agent.db` | 数据库连接串 |
| `CORS_ORIGINS` | 空 | 逗号分隔的前端来源 |
| `CHAT_TIMEOUT_SECONDS` | `120` | 单次聊天慢路径总超时，超时后如实提示且不继续执行 |
| `CHAT_SLOW_PATH_LIMIT_PER_MINUTE` | `20` | 单成员每分钟慢路径请求上限，`0` 表示关闭 |
| `HA_CALL_TIMEOUT_SECONDS` | `15` | 单次 Home Assistant 服务调用确认超时 |
| `ACCESS_TOKEN_MINUTES` | `120` | 访问令牌有效期 |
| `REFRESH_TOKEN_DAYS` | `7` | 刷新令牌有效期 |

LLM 的 provider、model、API Key、超时与 fallback 在 WebUI 的模型配置中维护，API Key 以 Fernet 加密后写入 `system_config`，接口返回时始终脱敏。

## 启动与停止

开发环境后端：

```bash
cd backend && ./.venv/Scripts/python.exe -m uvicorn app.main:app --host 127.0.0.1 --port 8233
```

开发环境前端：

```bash
cd frontend && npm run dev
```

生产构建：

```bash
cd frontend && npm run build
```

构建产物在 `frontend/dist`，由 Nginx 或其他静态服务器托管，`/api` 反向代理到 `127.0.0.1:8233`。后端启动命令保持单 worker：

```bash
cd backend && ./.venv/Scripts/python.exe -m uvicorn app.main:app --host 127.0.0.1 --port 8233 --workers 1
```

Windows 内测可用 NSSM 或任务计划程序托管该命令；Linux 使用 systemd，`Restart=always`、`RestartSec=5`。

## 健康检查与降级语义

- `GET /healthz`：进程存活探针，只返回 `{"status": "ok"}`，适合负载均衡和守护进程使用。
- `GET /readyz`：完整能力探针，检查数据库、Home Assistant WebSocket、LLM 是否已配置。任一项不满足返回 503，并在 `checks` 中列出原因。

LLM 全部不可用时，`/readyz` 会返回 503，但系统不会整体宕机：快路径仍可执行明确控制与状态查询；无法由快路径处理的请求会进入慢路径，并回复“大模型暂时不可用”，明确说明没有执行设备动作，同时给出可直接使用的指令示例。此时应使用 `/healthz` 判断进程是否存活，不要把 `/readyz` 503 直接等同于崩溃。

慢路径超时会返回“这次思考超时了”并说明后续步骤没有完成；限流会返回“请求有点频繁”。这两类回复都不会声称动作已完成。

## 日志与监控

- 后端结构化日志输出到 stdout，按启动命令重定向到 `logs/uvicorn.log`。
- 关键事件：`ha.snapshot.loaded`、`chat.fast_path_failed`、`chat.slow_path_timeout`、`chat.slow_path_rate_limited`、`chat.slow_path_failed`、`llm.usage.record_failed`。
- 建议监控：`/healthz` 连续失败次数、`/readyz` 状态、LLM 每日 `usage.llm.*` 错误计数、Home Assistant WebSocket 重连日志。
- 令牌、API Key、密码不会写入日志；排查时不要手工把完整请求头贴进日志或工单。

## 数据备份与恢复

数据库为 SQLite，运行时会产生 `agent.db`、`agent.db-wal`、`agent.db-shm`。

在线备份优先使用 SQLite 备份命令：

```bash
cd backend && ./.venv/Scripts/python.exe -c "import sqlite3; src=sqlite3.connect('data/agent.db'); dst=sqlite3.connect('data/backup-agent.db'); src.backup(dst); dst.close(); src.close()"
```

恢复步骤：停止后端，保留现场文件，将备份文件替换为 `data/agent.db`，删除旧的 `-wal` 与 `-shm`，再启动后端。备份文件应放在仓库之外并限制访问权限。

## 72 小时稳定性验收

启动后端并确认 `/healthz` 正常后，运行值守脚本。脚本每 30 秒采样一次，写入 `logs/soak.jsonl`，连续 3 次存活失败时以非零码退出：

```bash
SOAK_USERNAME=admin SOAK_PASSWORD=<管理员密码> backend/.venv/Scripts/python.exe tools/soak_monitor.py --hours 72 --interval 30
```

脚本会同时调用只读的快路径预览接口，记录延迟分位数，不会触发任何设备动作。

性能压测使用只读接口，同样不会控制设备：

```bash
SOAK_USERNAME=admin SOAK_PASSWORD=<管理员密码> backend/.venv/Scripts/python.exe tools/load_test_fastpath.py --requests 200 --concurrency 4
```

验收标准：

- 72 小时内进程无崩溃、无未处理异常导致的 500 持续增长
- `/healthz` 可用率 100%，重启次数为 0
- 快路径预览 p95 在正常范围内，无持续劣化
- LLM 不可用时快路径仍可控制，慢路径回复如实说明未执行
- Home Assistant 断线后能自动重连，状态缓存恢复

## 常见故障处理

Home Assistant 未连接：检查 `HA_BASE_URL` 与令牌；WebSocket 客户端按 1 秒到 30 秒指数退避重连，恢复后会自动刷新注册表和状态快照。`/readyz` 的 `ha_connected` 可用于确认。

LLM 请求失败：查看慢路径回复与 `usage.llm.*` 错误计数，检查 provider、API Key、网络与 fallback 配置。慢路径有单次调用超时、主模型重试和 fallback，仍失败时按降级路径处理。

SQLite 锁等待：连接已启用 WAL 与 5 秒 `busy_timeout`。持续出现锁错误时先确认没有多 worker 或多个后端实例同时写同一个数据库文件。

聊天超时或限流：调整 `CHAT_TIMEOUT_SECONDS` 与 `CHAT_SLOW_PATH_LIMIT_PER_MINUTE` 后重启后端。不要通过关闭限流来掩盖上游模型持续超时的问题。

## 安全要求

- 生产环境必须替换 `APP_SECRET_KEY`，并限制 `.env` 文件权限。
- Home Assistant 令牌与 LLM API Key 一旦出现在聊天、日志或截图中，立即轮换。
- 保持实体与服务白名单最小化；高风险动作必须经过提案确认。
- 不要执行来源不明的自动化 YAML；写入 Home Assistant 前必须经过校验与人工确认。
- 对外暴露时启用 HTTPS，并限制管理端访问来源。

## 升级与回滚

升级前备份数据库与 `.env`。后端升级后先跑全量测试，再重启单实例并观察 `/readyz` 与日志。前端重新构建并替换 `dist`。出现异常时回滚代码与前端产物，数据库保持向后兼容；若涉及表结构变更，使用升级前的备份恢复。
